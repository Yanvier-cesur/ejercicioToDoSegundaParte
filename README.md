## Todo-List v 0.1
Pequeña aplicacion para getionar lista de tareas desde la consola

## Funcionalidades

1. Añadir una nueva tarea
2. Borrar una tarea
3. Listar las tareas completas
4. Marcar una tarea como completada.

## Implementacion

- Se usa la **última versión de java** Jdk
- Almacenamiento de tareas en memoria usando `ArrayList`
- Gestión del UI con `println` y `Scanner`

## Modficiaciones

- He creado la posibilidad de al añadir tarea poder asignarle una prioridad pudiendo escribir `alta, media o baja`.
- En el segundo apartado he puesto que puedas filtrar por prioridad de alta a baja.
